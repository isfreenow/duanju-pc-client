# 短剧随心看

一个基于 **Rust + Tauri + React** 的竖屏短剧桌面客户端，支持浏览、搜索、分类、播放、观看进度记录与收藏等功能，界面为无边框自绘窗口，贴近原生桌面体验。

> 本仓库仅包含客户端源码与本地部署说明，不涉及任何服务端实现细节。

## 环境要求

在本地运行前，请先安装以下工具：

- **Node.js** 与 **pnpm**
- **Rust** 工具链（`rustc` / `cargo`）
- **Tauri v2** 的平台依赖，详见官方文档：<https://tauri.app/start/prerequisites/>
- **Windows**：需要 [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)（多数系统已随 Edge 内置）
- 播放部分片源依赖本机的 **HEVC（H.265）解码能力**，Windows 可从微软商店安装 HEVC 视频扩展。

## 本地部署

在项目根目录依次执行：

```bash
# 1. 安装前端依赖
pnpm install

# 2. 启动开发环境（会自动拉起前端与桌面窗口）
pnpm tauri dev
```

首次编译 Rust 侧耗时较长，属正常现象；窗口标题为「短剧随心看」。

## 打包发布

生成当前平台的可安装包：

```bash
pnpm tauri build
```

产物输出在 `src-tauri/target/release/bundle/` 目录下。

## 用 AI Agent（或脚本）直接唤起播放

程序认命令行参数，装好后把可执行文件路径交给 Agent 即可：说「我要看短剧〈剧名〉」，
Agent 提取剧名作为关键词拉起程序，程序自己走完 **搜索结果页 → 最匹配的那一部详情页 →
播放器**，看过就从上次那一集那一秒续播，没看过从第一集开头。

```powershell
# $APP = 可执行文件路径。安装版默认在 %LOCALAPPDATA%\hongguo-desktop-client\hongguo-desktop-client.exe
# （找不到就从开始菜单快捷方式右键 → 打开文件位置）；开发态在 src-tauri\target\debug\ 下同名。

& $APP --watch 持械入宋               # 搜关键词并开播
& $APP 持械入宋                      # 裸参数等价于 --watch
& $APP --series 7671966197985856536  # 跳过搜索，直接进这一部并开播

# 只查一次列表、不开窗口：打到 stdout 就退出，供 Agent 摆「1 号 / 2 号」选项
& $APP --search 持械入宋 | Out-String
#  1  持械入宋：第一季  ID 7671966197985856536  100集
#  2  持械入宋：第十季  ID 7697209269287914521  100集
```

- 用户回「就第 3 个」时，Agent 取那一行的 ID 再发一次 `--series`（序号只在本次列表
  里有效，站点顺序不保证跨次一致）。仓库里已带一个现成的技能
  `skills/duanju-search-play`（随仓库一起发布），把这两步串起来。
- 窗口已经在跑也没关系：再启动一次不会多开一个窗口，指令会转交给已经在跑的那个实例，
  窗口同时被拉回前台。
- 在第一页结果里挑标题最贴关键词的那一条，完全对不上就用第一条；搜失败（无结果 / 来源报错）
  就停在搜索结果页，不会自己乱点。
- 开发态下 `pnpm tauri dev` 转不出额外参数，用环境变量传同一件事：
  `$env:DUANJU_WATCH = "持械入宋"; pnpm tauri dev`（或 `DUANJU_SERIES`）。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `pnpm tauri dev` | 启动开发环境（前端 + 桌面窗口） |
| `pnpm tauri build` | 打包发布当前平台安装程序 |
| `pnpm run dev:vite` | 仅启动前端开发服务器 |
| `pnpm run build` | 类型检查并构建前端静态资源 |
| `pnpm run check` | 前端一致性检查（扫描、类型检查与构建） |

## 主要功能

- 首页热榜与「继续观看」推荐
- 分类浏览、关键词搜索、剧集详情页
- 内置播放器，支持横屏 / 竖屏自适应摆法与分集切换
- 观看进度自动记录，可续播
- 收藏夹管理
- 外部指令（命令行参数 / 环境变量）：AI Agent 列出带序号的搜索结果、按序号唤起开播与续播
- 无边框窗口与自绘标题栏
